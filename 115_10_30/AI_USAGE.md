# AI 使用紀錄（AI_USAGE）

## 一、使用目的
本次作業使用 AI 協助理解 Java 程式設計概念、整理實作步驟及檢查程式執行結果。

## 二、AI 協助項目

1. 陣列（Array）與陣列參考（Array Reference）的概念說明。
2. ArrayList 與 Collections 的使用方式。
3. CommandCounter 指令計數及索引範圍檢查。
4. MissionLog 任務紀錄、能源統計及歷程回放。
5. 協助分析程式錯誤及比較預測結果與實際輸出。
6. 協助整理 README 與實驗報告。

## 三、本人實作內容

1. 自行建立及修改 Java 程式。
2. 使用 VS Code 編譯及執行程式。
3. 依據不同測試資料觀察執行結果。
4. 記錄測試數據及整理實驗報告。
5. 檢查 AI 建議並透過實際執行確認結果。

## 四、使用原則

AI 僅作為學習與除錯輔助工具，程式修改、編譯、執行及結果確認均由本人實際操作。

## 五、使用心得

透過本次實作，更加理解 Java 陣列、集合、方法參數傳遞及程式執行歷程的概念，也學習如何運用 AI 協助分析錯誤並驗證程式結果。
