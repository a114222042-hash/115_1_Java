# 第四週學生實作：火星探測車任務日誌

## 一、專案簡介
本專案使用 Java 實作火星探測車任務模擬，
記錄探測指令、執行結果、能源變化及任務狀態。

## 二、實作內容
1. Java 陣列與陣列參考。
2. CommandCounter 指令計數。
3. ArrayList 動態紀錄資料。
4. Collections 排序與資料分析。
5. MissionLog 任務執行與歷程回放。
6. 任務統計與能源管理。

## 三、使用技術
- Java
- ArrayList
- Arrays
- Collections
- VS Code

## 四、主要程式
- MissionLog.java：任務執行與日誌紀錄。
- CommandCounter.java：指令統計。
- ArrayBasics.java：陣列基礎操作。
- ArrayReference.java：陣列參考傳遞。
- ListBasics.java：ArrayList 基礎操作。
- CollectionsDemo.java：集合排序與分析。

## 五、測試方式
使用 Java 編譯並執行 MissionLog.java，
確認任務結果、指令統計及能源紀錄。

## 六、專案成果
完成陣列、集合、任務紀錄及歷程回放等練習。
